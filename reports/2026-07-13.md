# Claude Code ベストプラクティス調査レポート 2026-07-13

## 今週の新発見

### `/doctor` コマンド ― セットアップ健全性チェック & 自動修正（v2.1.205）

**発見内容**: `/doctor`（エイリアス: `/checkup`）が「読み取り専用レポート」から「診断＋修正提案」に進化した。実行するとセッション内でインタラクティブに問題を検出し、確認を取ってから修正を適用する。

検出・修正できる項目:
- インストール健全性（バイナリ・Node バージョン等）
- **未使用のスキル・MCP サーバー・プラグイン**のコンテキストコスト比較
- ローカル `CLAUDE.md` とチェックイン済みファイルの**重複検出・マージ提案**
- Claude がコードベースから自力で導出できる `CLAUDE.md` 記述の**トリミング提案**
- **遅いフック**（ホットパスで 100ms 超）の検出

```text
> /doctor
```

修正前に必ず確認を求めるため、安全に実行可能。

**適用提案**:
- 月1回 `/doctor` を実行し、肥大化した CLAUDE.md と未使用 MCP の棚卸しを自動化する
- 新メンバーの環境セットアップ後に `/doctor` を走らせてインストール問題を即座に解消する
- `CLAUDE.md` の削除テスト（「これを削除しても Claude が間違えないか？」）と合わせて使い、100行以下を維持する

### Claude Sonnet 5 が新デフォルトモデル（v2.1.197+）

**発見内容**: Claude Sonnet 5 が Pro / Team Standard / Enterprise サブスクリプション席の新デフォルトモデルになった。

| 仕様 | 詳細 |
|-----|------|
| ネイティブコンテキスト | 1M トークン（ウィンドウ拡張なし） |
| Adaptive Thinking | デフォルト ON |
| API 価格 | $2/$10 per MTok（8月31日まで promotional） |
| 最低バージョン | v2.1.197 以降 |

```text
> /model claude-sonnet-5
```

組織のデフォルトモデルは管理コンソールから設定可能。設定済みの場合、`/model` に「Org default」と表示される。

**適用提案**:
- `~/.claude/settings.json` の `defaultModel` が古いモデルに固定されている場合は削除して Sonnet 5 への自動切替を有効にする
- エンタープライズ管理者は org コンソールで組織デフォルトモデルを Sonnet 5 に設定し、チーム全体で一貫したモデルを使用する
- 1M トークンコンテキストを活かして、これまで分割していた大規模コードベース解析を 1 セッションで実行できるか試す

### サブエージェントがバックグラウンド実行デフォルト化（v2.1.198）

**発見内容**: Claude はサブエージェントを起動した後、結果を待たずに作業を継続するようになった。サブエージェントが完了した時点で結果を取り込む。

**動作の変化**:

| 旧動作 | 新動作 |
|--------|--------|
| サブエージェント完了まで Claude が停止 | Claude はサブエージェント実行中も作業を継続 |
| 結果を順次受け取る | 完了した順に結果を受け取る |

フォアグラウンド実行が必要な場合（結果が次のステップに必要な場合）は Claude が自動判断して前面実行する。バックグラウンドサブエージェントのパーミッションプロンプトはメインセッションに表示される。

サブエージェント定義でピン留めする場合:

```markdown
---
name: security-reviewer
background: false   # 常にフォアグラウンド実行
tools: Read, Grep, Glob
---
```

**適用提案**:
- 並列化可能な調査タスク（「コードベースの複数領域を同時調査」等）でサブエージェントをより積極的に使い、待ち時間ゼロで複数調査を走らせる
- 結果に依存性がある場合は `background: false` をサブエージェント定義に明示して誤動作を防ぐ

### Auto Mode セキュリティ強化（v2.1.202+）

**発見内容**: Auto mode に複数のセキュリティ強化が加わった。

#### トランスクリプト改ざん防止

Auto mode がセッションのトランスクリプトファイルへの書き込みをブロックするようになった。これにより、外部コンテンツ（MCP サーバーのレスポンス、コードコメント等）に埋め込まれた「偽の承認」をトランスクリプトに注入する攻撃を防げる。

#### 未解決変数の `rm -rf` 前に確認

```bash
# 変数 $DIR が未解決のまま rm -rf を実行しようとすると確認ダイアログが出る
rm -rf $DIR
```

`$DIR` がコンテキストから解決できない場合、auto mode が実行前に確認を求める。

#### バックグラウンドタスク通知に「人間の入力なし」を明記

自動実行環境（Routines / CI）でのバックグラウンドタスク通知に「人間の入力は発生していない」ことが明示されるようになった。これにより、AI がトランスクリプト内のコンテンツを「人間の承認」として誤解釈することを防ぐ。

**適用提案**:
- CI 環境での `auto` モード + `--dangerously-skip-permissions` の組み合わせが不要になるケースが増えた。`--permission-mode auto` のみで安全な無人実行が可能かテストする
- `autoMode.classifyAllShell: true`（先週の発見）と組み合わせることで、完全な auto mode セキュリティスタックを構成できる

### Desktop アプリのビルトインブラウザ

**発見内容**: Claude Code Desktop アプリに組み込みブラウザが追加された。Claude が外部ドキュメント・デザイン・サービスのサイトを直接開いて操作できる。

| 機能 | 詳細 |
|------|------|
| 操作 | クリック・フォーム入力・ページ閲覧 |
| セキュリティ | サンドボックス化 + 安全性分類器がアクション監視 |
| セッション永続性 | ユーザーが設定可能 |
| 対応 | ローカル dev サーバープレビューと同じ操作 |

これにより、Playwright MCP なしでも基本的なブラウザ操作が可能になる（ただし Desktop アプリ限定）。

**適用提案**:
- デザインファイル（Figma 等）の参照や API ドキュメントの確認を Claude 自身に行わせ、コンテキスト汚染を減らす
- 外部サービスの認証が必要なページは MCP サーバーを使い続ける（ビルトインブラウザはセッション永続性設定に依存）

### フックのハイフン識別子マッチング仕様変更（v2.1.199）

**発見内容**: ハイフンを含む識別子（`code-reviewer`, `brave-search` 等）を持つ hooks が**部分一致**から**完全一致**に変更された。

```json
// 旧: "code-reviewer" が "code" を含む任意のツールにマッチしていた
// 新: "code-reviewer" は "code-reviewer" のみにマッチ

// MCP サーバー全体をマッチする場合はワイルドカードを使う
{
  "hooks": {
    "PreToolUse": [{
      "matcher": "mcp__brave-search__.*",
      "command": "echo 'brave search called'"
    }]
  }
}
```

**適用提案**:
- 既存フック設定でハイフン入り MCP サーバー（`brave-search`, `sequential-thinking` 等）を対象にしている場合、`.*` サフィックスを追加して全ツールをマッチさせる
- `/doctor` 実行でフック設定の問題も検出されるため、設定変更後に `/doctor` で確認する

### `/dataviz` スキル ― チャート・ダッシュボード設計ガイダンス

**発見内容**: 公式の `/dataviz` スキルが追加された。チャート・グラフ・ダッシュボードを作成する際の設計ガイダンスを提供し、カラーパレットバリデーターも内蔵している。

```text
> /dataviz
```

適用トリガー: chart / graph / plot / visualization / dashboard / analytics を含むタスク。

**適用提案**:
- データ可視化タスクの前に `/dataviz` を呼び出し、アクセシブルで一貫したデザインシステムを適用する
- チームの `references/palette.md` に独自ブランドカラーを定義して `/dataviz` の参照パレットとして使用する
