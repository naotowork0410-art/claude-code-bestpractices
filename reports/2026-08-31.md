# Claude Code ベストプラクティス調査レポート 2026-08-31

## 今週の新発見

今週は v2.1.238〜v2.1.251（2026-08-20〜08-28）の大量リリースから、前回レポート（v2.1.237）以降の新機能を整理した。

---

### Hooks: PreModelSwitch / PostModelSwitch（v2.1.251）

**発見内容**: モデル切り替えを Hooks でコントロールできる2イベントが追加された。

| イベント | タイミング | ブロック | 非同期 |
|---------|-----------|--------|-------|
| `PreModelSwitch` | モデル変更適用の直前 | 可（exit 2） | 不可 |
| `PostModelSwitch` | モデル変更後（自動変更含む） | 不可 | デフォルト async |

両イベントは `from_model`・`to_model` フィールドを受け取る（通常の `model` フィールドではない点に注意）。

**実用例（コスト管理ゲート）**:
```json
// ~/.claude/settings.json
{
  "hooks": {
    "PreModelSwitch": [
      {
        "matcher": "claude-opus-5",
        "hooks": [
          {
            "type": "command",
            "command": "bash -c 'echo \"{\\\"hookSpecificOutput\\\":{\\\"hookEventName\\\":\\\"PreModelSwitch\\\",\\\"permissionDecision\\\":\\\"deny\\\",\\\"permissionDecisionReason\\\":\\\"Opus 5 is blocked outside business hours\\\"}}\" && exit 2' 2>/dev/null",
            "timeout": 5
          }
        ]
      }
    ],
    "PostModelSwitch": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "echo \"[model] ${from_model} → ${to_model}\" >> ~/.claude/model-switch.log",
            "async": true
          }
        ]
      }
    ]
  }
}
```

**適用提案**:
- チーム環境では `PreModelSwitch` + `permissionDecision: "deny"` で高コストモデルへの切り替えを制御
- `PostModelSwitch` で切り替えログを記録し、コスト分析に活用（async で遅延ゼロ）
- `SessionStart` の `resume` フック同様、`PostModelSwitch` はセッション再開時の自動モデル復元でも発火する点に注意

### settings.json 新項目: プロンプトキャッシュ TTL 制御（v2.1.243 / v2.1.248）

**発見内容**: プロンプトキャッシュの保持時間を設定とエージェントフロントマターで個別制御できるようになった。

```json
// ~/.claude/settings.json
{
  "promptCacheTtl": 3600,          // メインセッションのキャッシュTTL（秒）
  "subagentPromptCacheTtl": 1800   // サブエージェントのキャッシュTTL（秒）
}
```

```yaml
# .claude/agents/long-running-agent.md
---
name: long-running-agent
description: 長時間バッチタスク用エージェント
experimental:
  cacheTtl: 7200    # このエージェント専用のTTL（v2.1.248+）
---
```

**適用提案**:
- Routines（スケジュール実行）はセッションを何度も再起動するため `promptCacheTtl` を長めに設定してキャッシュミス削減
- 長時間サブエージェント（コードレビュー・大規模探索）には `experimental.cacheTtl` をフロントマターで指定
- v2.1.248 の修正で「1時間に1回キャッシュミスが発生する」バグが解消されたため、既存の回避策（短いTTL設定）は削除可能

### settings.json 新項目: modelPicker / modelPricing（v2.1.243）

**発見内容**: `/model` ピッカーに表示するモデルをカスタマイズし、組織の契約レートを設定できる。

```json
// ~/.claude/settings.json または managed-settings.d/20-models.json
{
  "modelPicker": [
    { "id": "claude-sonnet-5", "label": "Sonnet 5 (default)" },
    { "id": "claude-opus-5",   "label": "Opus 5 (heavy tasks)" },
    { "id": "claude-haiku-4-5-20251001", "label": "Haiku 4.5 (fast)" }
  ],
  "modelPricing": {
    "claude-opus-5": {
      "inputMtokCost": 12.00,
      "outputMtokCost": 60.00,
      "cacheWriteMtokCost": 1.50,
      "cacheReadMtokCost": 0.30
    }
  }
}
```

**適用提案**:
- `modelPicker` でチームに不要なモデルを非表示にしてピッカーをシンプルに保つ
- `modelPricing` を managed settings に配置すると `/cost` の表示が組織の実際の請求額と一致する（Enterprise 契約での割引レートに対応）
- `availableModels` + `enforceAvailableModels` と組み合わせて「選択は自由だが表示は整理済み」の運用が可能

### セキュリティ強化: --restricted フラグ（v2.1.248）

**発見内容**: コマンド実行ツールを丸ごと除去し、作業ディレクトリ内のファイルツールのみ残す `--restricted` フラグが追加された。

```bash
# コマンドツールなし、ファイルツールのみで起動
claude --restricted

# 安全な自動化パイプラインに組み込む場合
claude --restricted -p "Review the changes in src/ and suggest improvements" \
  --output-format json
```

**v2.1.251 で修正されたパストラバーサル脆弱性**:
- File Read/Write/Edit がシンボリックリンク経由の作業ディレクトリ外アクセスをブロック
- Plugin コマンドとワークフロースクリプトで同様の修正
- 既存の `sandbox.filesystem.disabled` と組み合わせた二重防御も有効

**適用提案**:
- CI/CD パイプラインでの Claude Code 実行は `--restricted` をデフォルトに
- コードレビュー専用の読み取りエージェントは `--restricted` + `permissionMode: plan` の組み合わせが最安全
- Wildcard Bash allow rules（`Bash(*)`）への v2.1.246 起動時警告を確認し、過度に広い許可を修正する

### コスト管理強化: ループ別 usage 分析 + /claude-api cost-optimize（v2.1.243 / v2.1.247）

**発見内容**: `/usage` でループ（Routine/スケジュール実行）ごとのトークン消費を詳細分解できるようになり、`/claude-api cost-optimize` でコードからAPIコストを最適化できる。

**`/usage` の新 Loops Breakdown**:
```
/usage
───────────────────────────────────────────
Loops breakdown:
  weekly-bestpractices   runs: 4   tokens: 1.2M   last: 2026-08-31 02:00
  daily-ci-monitor       runs: 7   tokens: 0.4M   last: 2026-08-30 23:00
  pr-babysitter          runs: 12  tokens: 0.8M   last: 2026-08-31 01:30
───────────────────────────────────────────
Spend limit: $45.20 / $100.00 [████████░░░░░░░░░░░░]
```

**`/claude-api cost-optimize`**:
- Python プロジェクトのコードを解析してキャッシュ未活用箇所・不必要な出力トークン・モデル選択ミスを検出
- 改善提案をコードと一緒に提示（適用は手動）

**`rate_limits.spend_limit` ステータスラインフィールド（v2.1.251）**:
```json
// ~/.claude/settings.json
{
  "statusLine": "{{ rate_limits.spend_limit }} | {{ context_pct }}%ctx | {{ model }}"
}
```

**適用提案**:
- `/usage` の Loops Breakdown で消費の大きい Routine を特定し、`outputStyle: "Concise"` + `maxTurns` 削減で最適化
- `rate_limits.spend_limit` をステータスラインに表示して支出上限を常時モニタリング
- `/claude-api cost-optimize` は SDK 使用プロジェクトで月次実行する習慣をつける

### ユーザビリティ改善: スペルチェック・ターン時間・auto mode タブ（v2.1.235 / v2.1.246）

**発見内容**: プロンプト入力のスペルチェック、ターン完了時間の表示、auto mode のルール管理タブが追加された。

**スペルチェック設定（v2.1.235）**:
```json
// ~/.claude/settings.json
{
  "spellcheck": true   // aspell / hunspell / ispell が自動検出される
}
```

**ターン完了時間**: end-of-turn の duration 行に完了時刻が追記される（ログ分析で役立つ）

**Auto mode タブ（v2.1.246）**: `/permissions` に auto mode 専用タブが追加され、Classifier ルールをビジュアルで管理可能

**`notify_when_idle`（v2.1.236）**:
```json
// クロスセッション SendMessage でレスポンスを待つ場合
{
  "notify_when_idle": true   // macOS/Linux でセッションがアイドルになったら通知
}
```

**適用提案**:
- 英語プロンプトをよく入力する場合は `spellcheck: true` を `settings.local.json` に追加
- `notify_when_idle` は複数セッション間の連携（Writer/Reviewer パターン等）で有効
- `/permissions` の auto mode タブで既存の wildcard ルールを見直す（v2.1.246 の起動時警告と合わせて）

### その他の注目アップデート

**v2.1.239: `/claude-api upgrade`**
- `anthropic` Python SDK の 0.x → 1.x マイグレーションを自動化
- SDK 1.x は `client.beta.messages.tool_runner` (Tool Runner) などの新機能に必要

**v2.1.238: Proxy Authorization**
- `--proxy-authorization-command` / `--proxy-authorization-file` でプロキシ認証を外部コマンド経由で動的取得
- 短命トークン（JWT等）を都度生成するゼロトラスト環境に対応

**v2.1.236: `ANTHROPIC_DEFAULT_MODEL`**
- 環境変数で新セッションのデフォルトモデルを指定
- `direnv` + `.envrc` で作業ディレクトリごとにモデルを切り替える運用が可能

```bash
# .envrc（direnv使用）
export ANTHROPIC_DEFAULT_MODEL=claude-haiku-4-5-20251001  # 軽量タスク用ディレクトリ
```
